# Club Hub

Club Hub is a mobile-first grassroots football club management platform for clubs, teams, coaches, players and guardians.

## Foundation

- Next.js App Router
- TypeScript
- Tailwind CSS
- PostgreSQL-ready data model
- Role-based access foundation
- Club, team, player, fixture, training, attendance and messaging domains

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000.

## Build roadmap

1. Platform foundation: authentication, clubs, teams, members, roles and onboarding
2. Weekly operating loop: dashboard, calendar, fixtures, training, attendance and messaging
3. Coaching workspace: drill library, session planner and tactical editor
4. Player development: profiles, goals, notes and progress
5. Club operations: payments, fundraising, documents and safeguarding
6. Public club site: news, fixtures, sponsors and Club TV
7. Production hardening: testing, accessibility, security and deployment
